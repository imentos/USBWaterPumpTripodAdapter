# V7 Pure Cylinder — Four Through-Windows

V7 is rebuilt completely from scratch and does not import Tyler's shoulder
pillars or lower-body geometry.

## Geometry

- One straight cylinder: 57.15 mm OD, 46.4 mm tall.
- One straight internal bore: 42.0 mm ID.
- Constant radial wall thickness: 7.575 mm.
- Four 29 x 23 mm through-windows, spaced 90 degrees apart.
- No separate pillars, outside ribs, inset pockets, or stepped inner walls.
- 2.2 mm structural floor joined directly to the integrated quick-lock hub.
- All three bayonet-lug bottom faces are coplanar with the center pilot bottom,
  so both features start on the print bed without support.
- Every V7 base receiver track is shifted 0.8 mm downward to match the revised
  lug height while retaining the original assembly clearances and 30-degree stop.
- O-ring groove: 2.0 mm wide, 0.40 mm deep, centered 0.2 inch below the top.
- Tripod Base contains Tyler's original modeled 1/4-20 internal thread copied
  directly from his STEP geometry. It screws directly onto a tripod and does
  not use a metal insert.
- No V7 base contains an M4 safety-lock or heat-set-insert hole. Tripod,
  weighted, magnetic, and the fit coupon all rely on the three-lug bayonet
  track and the approximately 30-degree positive stops.

The material naturally remaining between adjacent windows is part of the same
curved cylindrical wall. It is flush inside and outside, not a pillar feature.

## First print

Print `v7_pure_cylinder_four_windows.stl` and
`v7_receiver_fit_coupon.stl`. Check pump retention, O-ring compression, hose
routing through all four windows, and the 30-degree quick-lock fit before
printing a complete base.
